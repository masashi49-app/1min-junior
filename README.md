# 1min Junior ✨

小学4年生向けの、運動・ピアノ・絵本の習慣アプリ。「1分でもOK」。
ビルド不要・外部ライブラリ不要の静的PWAです。

## GitHub Pagesへの配置

1. **新しいリポジトリ `1min-junior`** を用意します。既存の中1版リポジトリは使いません。
2. このフォルダの中身をリポジトリのルートに配置します。`index.html` がルートにある形です。
3. GitHub Pagesの公開元を、このファイルを置いたブランチのルートに設定します。
4. 公開されたHTTPSのURLをSafariで開きます。

ソースファイル以外（JSONバックアップ・CSV・端末の記録）は、公開リポジトリへアップロードしないでください。
`.nojekyll`も含めて配置してください。`tests/`と文書は公開に必須ではありません。

## iPhoneで使う

Safariで公開URLを開き、共有メニューの「ホーム画面に追加」を選びます。
追加時の名前は **1min Junior ✨**。ホーム画面から起動すると独立した画面で開きます。
端末や表示設定によって、長いアイコン名は省略表示されることがあります。
初回はオンラインで開いてキャッシュを準備してください。以後はオフラインでも記録できます。
ホーム画面版で記録を始め、その画面を継続して使ってください。

## 記録のルール

- 大きなボタンをタップして「できた！」。もう一度タップすると解除。
- 1項目でもできた日を1日として数えます。
- 連続日数は今日から逆に数えます。今日が未達成なら昨日から数え、今日の途中では途切れません。
- 累積日数は、1項目以上できた日の総数。連続が途切れても減りません。
- 過去の日を全解除した場合は、その日は累積からも除かれます。
- カレンダーは右スワイプで前月、左スワイプで翌月。矢印でも移動できます。
- 今日・過去の日付をタップすると編集できます。保存するまで変更は反映しません。
- 日付の区切りは端末のローカル日付です。起動したまま日付が変わっても更新します。

## 保存とバックアップ

端末内のlocalStorage（`oneMinJunior.v1`）だけに保存します。
中1版の保存キー `oneMin.v1` を読み書きしません。サーバー・解析・外部フォントは使いません。
表示名の入力機能は設けず、個人名は扱いません。

下部の「記録のバックアップ」からJSONを共有・保存できます。
共有先にpCloudなどの非公開フォルダを選んでください。CSVは閲覧用、復元はJSONを使います。
JSON復元は**現在の全記録の置換**です。画面で確認してから実行します。
別アプリのJSON、不正な日付・項目・未来の記録は拒否し、元データを保ちます。

ブラウザデータの消去、端末交換、保存領域の整理で記録が失われる場合があるため、ときどきJSONを保存してください。
端末間の自動同期はありません。同じGitHub PagesドメインのコードからlocalStorageへアクセスできるため、同一ドメインには信頼できるアプリだけを配置してください。

## ファイル

- `index.html` / `style.css` / `app.js`：画面と操作
- `core.js`：日付・集計・復元形式
- `manifest.json` / `service-worker.js`：PWAとオフライン
- `assets/tiara.png`：プロジェクトで作成済みのティアラ画像（原本を変更せず使用）
- `assets/icon-*.png` / `apple-touch-icon.png`：ホーム画面アイコン
- `TESTING.md`：確認結果と実機確認手順

更新時は `service-worker.js` の `VERSION` を変更し、全ファイルをまとめて配置します。
旧画面をすべて閉じて開き直すと、新しいキャッシュへ切り替わります。
キャッシュ名はアプリのURL範囲を含み、中1版のキャッシュを削除しません。

## テスト

`node tests/logic.cjs` と `node tests/service-worker.cjs` で集計・復元・キャッシュ隔離を確認できます。
DOMテストは `jsdom` を利用します（公開アプリには不要）。
